# Tax-aware rebalancing

Use invest to inspect accepted portfolio state, lot integrity, source dates, account restrictions, and available cash. Generate a plan against a saved target with separate short-term and long-term gain budgets. Review proposed account actions, specified taxable lots, estimated tax effects, wash-sale limitations, and remaining drift. Use the existing simulator rather than calculating a separate portfolio model. Save and export a report, clearly disclosing unresolved prices, basis, history, or eligibility. Every plan requires a human decision and manual trade execution.
