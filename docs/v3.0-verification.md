failures and 84 passes** before fixes: fabricated SEC-homepage identity, a
conflicting retained accession query, an explicit no-waiver statement, missing
limitations despite declared complete scope, and TOP_N saved-package roundtrip
with IDs whose alphabetical order differs from weight order. New tests are
committed red before any corresponding production correction.

An independent skill forward evaluation validated, previewed, accepted and read
fictional ETF and ACTIVE mutual-fund Class I packages in isolated offline Docker.
A wheel built after `uv sync --locked --offline` includes all five new skill files
byte-identical to the canonical bundle. This installed uv does not support
`uv build --locked`; `uv build --offline` used the already locked environment.

The frozen review corrections pass **862 tests** and explicit-config Ruff in
source-mounted offline Docker. Missing important disclosures require limitations
even when the declared review scope is complete. SEC identity requires a genuine
filing accession path or explicit original EDGAR series/class record; retained
URL accessions cannot contradict source metadata. Explicit no-waiver statements
remain ordinary fee facts. Stable-ID hashing remains unchanged while serialized
TOP_N packages keep descending weights for validated, idempotent roundtrips.
