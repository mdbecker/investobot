# Exposure and quantitative analysis
`portfolio exposure` combines direct securities with every available fund constituent. Decimal weights are fractions; output percentages are percentage points. Contributions identify synthetic accounts and funds. Partial holdings allocate only their known fraction; missing/unsupported exposure is reported explicitly. Weights are never rescaled, and inconsistent totals over 100% leave the fund unknown. Cash is included in the household denominator. Sectors/asset classes only appear when supplied by structured data. Provider provenance remains visible in the result.

`portfolio risk` uses aligned dividend-adjusted historical prices and reports the exact usable dates, possible missing sessions, pairwise correlations, HHI and current position concentration. The backtest is a current-weight, rebalanced-per-observation scenario, not realized account performance; cash return is assumed zero and fees/taxes are excluded. Missing invested-asset history causes INSUFFICIENT_DATA, not an invented price series. Volatility uses sample standard deviation and252 sessions/year.

`portfolio simulate actions.json` accepts a nonempty JSON array of BUY/SELL/MOVE_CASH actions. It deep-copies positions, cash, lots and activities, and suppresses cache writes as well as ledger writes. Sale lot selection and known hypothetical purchases inform tax/wash warnings. New buys require an already-resolved canonical security. Tax data gaps propagate as null gains with warnings. Import the candidate as a zero-quantity manual normalized position if needed; no security identity is invented from a ticker during simulation.

Household calculations require a single account currency. Mixed currencies fail with inconsistent-state exit code3; no FX conversion is invented. A single non-USD currency is preserved in summary/exposure output and inspection formatting. Explicit CUSIP/ISIN/FIGI bridges normalize direct and fund holdings before aggregation. Missing source dates in HTML are warned; import-date position timestamps are not presented as identified upstream dates.
